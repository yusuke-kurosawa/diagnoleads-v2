## はじめに

### アカウント作成

1. サインアップページ（`/signup`）にアクセス
2. 以下の情報を入力：
   - メールアドレス
   - パスワード（8文字以上）
   - 名前
3. 「アカウント作成」をクリック
4. 確認メールのリンクをクリックして認証完了

### ログイン

1. ログインページ（`/login`）にアクセス
2. メールアドレスとパスワードを入力
3. 「ログイン」をクリック

### 組織の作成・切り替え

DiagnoLeadsは複数の組織に所属できます。

**組織の作成:**
1. 左上の組織名をクリック
2. 「新しい組織を作成」を選択
3. 組織名とスラッグを入力
4. 「作成」をクリック

**組織の切り替え:**
1. 左上の組織名をクリック
2. 切り替えたい組織を選択

## ダッシュボード

ダッシュボードでは、リードの概要とパフォーマンス指標を確認できます。

### メトリクス

| 指標 | 説明 |
|------|------|
| 総リード数 | 獲得したリードの総数 |
| 新規リード | 期間内に獲得した新規リード数 |
| コンバージョン率 | リードがコンバージョンに至った割合 |
| 平均スコア | リードスコアの平均値 |

### トレンドチャート

- 日次・週次・月次でリード獲得推移を確認
- 期間を選択して比較分析が可能

### ソース分析

リードの流入元を分析：
- ウェブサイト
- ソーシャルメディア
- メール
- 広告
- リファラル

## リード管理

### リード一覧

リード管理ページ（`/leads`）では、すべてのリードを一覧表示できます。

**機能:**
- 検索（名前、メール、会社名）
- フィルタリング（ステータス、ソース、タグ）
- ソート（日付、スコア、名前）
- ページネーション

### リードステータス

| ステータス | 説明 |
|-----------|------|
| New | 新規リード |
| Contacted | 連絡済み |
| Qualified | 見込み確認済み |
| Converted | 成約 |
| Lost | 失注 |

### リード詳細

リードをクリックすると詳細情報を確認できます：

- 連絡先情報
- 診断回答
- リードスコア
- タグ
- コメント履歴
- アクティビティログ

### タグ管理

タグでリードを分類：
1. リード詳細で「タグを追加」をクリック
2. 既存タグを選択または新規作成
3. 色を選択して保存

### エクスポート

リードデータをエクスポート：
1. エクスポートボタンをクリック
2. フォーマットを選択（CSV/PDF）
3. エクスポート範囲を選択
4. ダウンロード

## 診断フォーム

### 診断の作成

管理者は診断テンプレートを作成できます。

**ステップ:**
1. 「診断テンプレート」ページへ移動
2. 「新規作成」をクリック
3. 基本情報を入力
   - タイトル
   - スラッグ
   - 説明
4. ステップを追加
5. 各ステップに質問を追加
6. 完了ページを設定
7. 保存

### 質問タイプ

| タイプ | 説明 |
|--------|------|
| テキスト | 自由入力 |
| 選択式 | 単一選択 |
| 複数選択 | 複数選択可 |
| スケール | 数値スケール（1-10など） |
| メール | メール形式バリデーション |
| 電話 | 電話番号形式 |

### A/Bテスト

診断フォームのパフォーマンスを最適化：

1. 「A/Bテスト」ページへ移動
2. 「新規テスト」を作成
3. バリアントを設定
4. トラフィック配分を設定
5. テストを開始
6. 結果を分析

## アナリティクス

### 概要ダッシュボード

主要KPIを一目で確認：
- リード獲得数
- コンバージョン率
- 平均リードスコア
- ソース別パフォーマンス

### レポート機能

**標準レポート:**
- 期間比較レポート
- ソース分析レポート
- ファネル分析レポート
- ROI計算レポート

**カスタムレポート:**
1. 「レポートビルダー」を選択
2. ウィジェットを配置
3. データソースを設定
4. 保存して共有

### データのエクスポート

アナリティクスデータをエクスポート：
- CSV形式
- PDF形式
- 自動レポート配信（スケジュール設定可能）

## 設定

### プロフィール設定

個人設定を管理：
- 名前の変更
- メールアドレスの変更
- パスワードの変更
- 言語設定（日本語/英語）

### 組織設定

組織管理（オーナー/管理者のみ）：
- 組織名の変更
- ロゴの設定
- タイムゾーン設定

### メンバー管理

チームメンバーを管理：
1. 「メンバー」設定を開く
2. 「メンバーを招待」をクリック
3. メールアドレスと役割を入力
4. 招待メールを送信

**役割:**
| 役割 | 権限 |
|------|------|
| オーナー | すべての権限 |
| 管理者 | 設定変更可能 |
| メンバー | 閲覧と基本操作 |

### Webhook設定

外部サービスとの連携：
1. 「Webhook」設定を開く
2. 「新規作成」をクリック
3. エンドポイントURLを入力
4. イベントを選択
5. 保存

**利用可能なイベント:**
- `lead.created` - 新規リード作成時
- `lead.updated` - リード更新時
- `lead.status_changed` - ステータス変更時
- `diagnostic.submitted` - 診断送信時

## サポート

### よくある質問

**Q: パスワードを忘れました**
A: ログインページの「パスワードを忘れた方」からリセットできます。

**Q: リードをまとめて編集できますか？**
A: リード一覧でチェックボックスを選択し、一括操作を実行できます。

**Q: データをバックアップできますか？**
A: エクスポート機能でCSV形式でダウンロードできます。

### お問い合わせ

技術的なサポートが必要な場合は、管理者にお問い合わせください。
