# DiagnoLeads v2 機能一覧

## 概要

DiagnoLeads v2は、エンタープライズグレードの診断リード管理プラットフォームです。
AI駆動のリードスコアリング、マルチテナント対応、ホールディングス・グループ企業向けの階層構造管理を特徴としています。

## ⚙️ ワークフロー自動化

### ワークフロー機能
| 機能 | 説明 |
|------|------|
| ワークフロー作成・管理 | 自動化ルールの設定 |
| 有効/無効切り替え | ワークフローのオン/オフ |
| 実行履歴 | ワークフロー実行ログ |
| 統計情報 | 実行回数、成功率 |

### トリガー (7種類)
- lead_created: リード作成時
- lead_updated: リード更新時
- lead_deleted: リード削除時
- status_changed: ステータス変更時
- score_changed: スコア変更時
- tag_added: タグ追加時
- scheduled: スケジュール実行

### アクション (7種類)
- update_status: ステータス変更
- update_score: スコア更新
- add_tag: タグ追加
- remove_tag: タグ削除
- send_email: メール送信
- send_webhook: Webhook送信
- assign_owner: 担当者割り当て

### 条件演算子 (12種類)
- equals, not_equals
- contains, not_contains
- starts_with, ends_with
- greater_than, less_than
- greater_than_or_equals, less_than_or_equals
- is_empty, is_not_empty
