## 🎯 プロダクト概要

**DiagnoLeads v2** は、ホールディングス・グループ企業・エンタープライズ向けの **AI駆動B2B診断プラットフォーム** です。

### コアコンピタンス（最重要）

> **これは単なるマルチテナントSaaSではありません。階層的組織構造に対応した、エンタープライズグレードのプラットフォームです。**

| 一般的なマルチテナントSaaS | DiagnoLeads v2 |
|---------------------------|----------------|
| 組織単位のデータ分離 | 組織単位のデータ分離 |
| フラットな組織構造のみ | **階層的組織構造**（親会社-子会社-孫会社） |
| 組織間連携なし | **グループ横断レポート・分析** |
| M&A時に手動対応 | **ビルトインM&A対応** |
| 単一組織レポート | **グループ統合ダッシュボード** |

### ターゲット顧客

1. 🏢 **ホールディングス** - 複数事業会社を持つ持株会社
2. 🌐 **グループ企業** - 親会社-子会社-孫会社構造を持つ企業グループ
3. 📈 **M&A実行企業** - 買収・合併による成長戦略を取る企業
4. 🏗️ **カンパニー制企業** - 社内カンパニー制を採用する大企業
