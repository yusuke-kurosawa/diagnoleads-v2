# MemoryBank

> Droidのセッション間記憶を管理するディレクトリ

---

## 概要

MemoryBankは、Droid（AI Agent）がセッション間で一貫した判断を行うための永続的な記憶システムです。

---

## ファイル構成

| ファイル | 目的 | 更新頻度 | 重要度 |
|----------|------|---------|--------|
| `violations.md` | **原則違反記録** | 違反発生時 | **必読** |
| `decisions.md` | 意思決定の履歴 | 重要な決定時 | 必読 |
| `preferences.md` | ユーザーの好み・スタイル | 好み判明時 | 必読 |
| `learnings.md` | 学習・教訓・成功パターン | 問題解決後 | 必読 |

---

## 使用方法

### Droidへの指示

CLAUDE.mdまたはAGENTS.mdに以下を追加:

```markdown
## MemoryBank

セッション開始時に以下を参照:
- `.factory/memory/decisions.md` - 過去の意思決定
- `.factory/memory/preferences.md` - ユーザーの好み
- `.factory/memory/learnings.md` - 過去の学習

重要な決定・学習があれば、該当ファイルに追記する。
```

---

## 記録のガイドライン

### decisions.md に記録すべき内容
- 技術選定（ライブラリ、フレームワーク）
- 設計判断（アーキテクチャ、パターン）
- 命名規則の決定
- プロセスの決定

### preferences.md に記録すべき内容
- コミュニケーションスタイル
- コーディングスタイル
- 作業の進め方
- 避けるべきこと

### learnings.md に記録すべき内容
- 発生した問題と解決策
- 失敗パターン
- 成功パターン
- ベストプラクティス

---

## メンテナンス

### 定期レビュー（月1回推奨）
- 古くなった決定の更新・アーカイブ
- 重複した教訓の統合
- 不要な情報の削除

### アーカイブ基準
- 6ヶ月以上更新されていない決定
- プロジェクトに関係なくなった情報
- 技術的に陳腐化した内容
